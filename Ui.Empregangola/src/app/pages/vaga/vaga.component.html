Oportunidade em Luanda, com modelo de trabalho híbrido.

Como Desenvolvedor(a) C#/.NET Pleno, vai trabalhar para o nosso cliente, uma empresa tecnológica dinâmica, comprometida em fornecer soluções de software robustas. Vai contribuir para a construção de sistemas backend robustos e integração de interfaces frontend, moldando experiências digitais inovadoras. Esta função oferece um caminho de crescimento numa indústria em constante evolução.

As suas principais responsabilidades:

  • Desenvolver e manter aplicações backend usando C# e frameworks .NET, garantindo alto desempenho e escalabilidade.
  • Colaborar no desenvolvimento frontend com Angular (uma mais-valia), integrando elementos de interface com lógica de servidor.
  • Desenhar, implementar e consumir serviços de API REST para facilitar a interoperabilidade de sistemas.
  • Escrever código limpo, eficiente e bem documentado, seguindo os princípios SOLID e KISS.
  • Participar em revisões de código e promover boas práticas durante a aprovação de Pull Requests.
  • Utilizar SQL Server para gestão, optimização e integridade de dados.
  • Implementar e manter frameworks de testes automatizados usando NUnit e xUnit.

É ideal para esta função se tiver:

  • 3+ anos de experiência em desenvolvimento de software C#/.NET.
  • Experiência sólida com bases de dados Microsoft SQL Server.
  • Experiência comprovada em programação de aplicações backend usando C#.
  • Familiaridade com desenvolvimento frontend em Angular (mais-valia).
  • Experiência a desenhar e trabalhar com serviços de API REST.
  • Forte compreensão dos princípios de design SOLID e KISS.
  • Experiência com metodologias ágeis, especialmente SCRUM.

É uma mais-valia se tiver:

  • Experiência com Azure DevOps, Bitbucket, XLDeploy, XLRelease.
  • Conhecimento de Elastic Stack (Elasticsearch e Kibana).
  • Certificação ou experiência em segurança de aplicações.
  • Familiaridade com automação CI/CD e processos de deployment.

Idioma exigido para a função:

  • Fluência em Português (mínimo nível B2).

Elegibilidade para a função:

  • Apenas candidatos com direito legal de trabalho em Angola serão considerados para esta função.
